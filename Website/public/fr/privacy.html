Confidentialité

Routine 1.1.0 · Mis à jour le 3 novembre 2026

Vos routines et iCloud

Vos routines, vos progrès, votre historique et vos réglages de rappel sont stockés sur votre appareil. Lorsqu’iCloud est disponible, Routine peut les synchroniser via CloudKit d’Apple à l’aide de votre compte Apple. Les réglages iCloud et de sauvegarde d’Apple régissent ces services. Routine n’a ni compte distinct ni serveur de synchronisation propre.

Rappels et verrouillage de l’app

Les rappels utilisent des notifications locales avec votre autorisation. Le système d’exploitation gère l’authentification par Face ID, Touch ID et code de l’appareil. Routine ne reçoit pas de modèles biométriques. Vous pouvez gérer les autorisations dans les réglages du système.

Analyse d’usage et assistance

Routine n’intègre ni outils d’analyse d’usage du développeur, ni traceurs publicitaires, ni service tiers de rapports de plantage. L’app et le système d’exploitation peuvent produire des journaux de diagnostic locaux.

Si vous choisissez d’écrire à l’assistance, le brouillon de l’app inclut la date, le modèle de l’appareil, la version du système d’exploitation et celle de l’app. Vérifiez ou supprimez ces informations avant l’envoi. L’assistance ne reçoit que ce que vous choisissez d’envoyer ; évitez les informations privées sur vos routines. Les services de messagerie et GitHub ont leurs propres politiques de confidentialité, et les signalements GitHub sont publics.

Suppression des données

Sur iPhone et iPad, supprimer l’app efface normalement ses données locales. Sur Mac, la suppression de l’app peut laisser son conteneur local et les données partagées App Group. Les données CloudKit et les sauvegardes iCloud peuvent rester associées à votre compte Apple et nécessitent une gestion séparée dans les réglages de stockage iCloud d’Apple. Supprimer l’app ne garantit pas la suppression de toutes les copies. Contactez l’assistance pour vous aider à identifier les données Routine stockées.

Ce site web

Ce site web utilise Cloudflare Web Analytics pour mesurer les visites et les performances sans cookies d’analyse. Il est hébergé par GitHub Pages, qui peut traiter des informations sur les requêtes, dont votre adresse IP, pour servir et sécuriser le site. Consultez la déclaration de confidentialité de GitHub.
