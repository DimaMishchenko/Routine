支持

需要帮助？请发送邮件至 dimasike.dev@gmail.com.

请提供应用版本、设备型号以及 iOS、iPadOS 或 macOS 版本，并说明预期结果和实际发生的情况。请遮挡截图中的私人习惯信息，并在发送前检查所有诊断文本。切勿发送密码或验证码。

如需报告可复现的问题或提出功能建议，请使用 GitHub Issues。Issue 内容公开可见：私人信息请仅通过邮件提供。

为什么收不到提醒？

请检查该习惯的提醒时间，并在系统设置中允许 Routine 发送通知。同时检查专注模式或通知摘要是否导致通知延迟。

为什么设备之间没有同步？

请确认每台设备都使用同一个 Apple 账户、已启用 iCloud 且已连接互联网。如果问题仍然存在，请先通过邮件联系支持，再考虑删除应用或其数据。

如何更改应用锁定设置？

打开 Routine 的设置以更改身份验证方式。Face ID、Touch ID 或设备密码是否可用，取决于你的设备和系统设置。
