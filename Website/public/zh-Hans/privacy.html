隐私

Routine 1.1.0 · 更新于 2026 年 11 月 3 日

你的习惯数据与 iCloud

你的习惯、进度、历史和提醒设置存储在你的设备上。iCloud 可用时，Routine 可以使用你的 Apple 账户，通过 Apple 的 CloudKit 同步这些数据。这些服务受 Apple 的 iCloud 和备份设置管理。Routine 没有独立账户或同步服务器。

提醒与应用锁定

提醒会在获得你的许可后使用本地通知。Face ID、Touch ID 和设备密码身份验证由操作系统处理。Routine 不会接收生物识别模板。你可以在系统设置中管理权限。

分析统计与支持

Routine 不包含开发者分析统计、广告跟踪器或第三方崩溃报告功能。应用和操作系统可能会生成本地诊断日志。

如果你选择通过邮件联系支持，应用生成的邮件草稿会包含日期、设备型号、操作系统版本和应用版本。请在发送前检查或移除这些信息。支持人员只能收到你选择发送的内容；请勿包含私人习惯信息。电子邮件和 GitHub 各有自己的隐私政策，GitHub 的 Issue 内容公开可见。

删除数据

在 iPhone 和 iPad 上，删除应用通常也会移除应用的本地数据。在 Mac 上，移除应用后，其本地应用容器和共享 App Group 的数据可能仍会保留。CloudKit 数据和 iCloud 备份可能仍保留在你的 Apple 账户下，需要通过 Apple 的 iCloud 存储设置单独管理。删除应用并不保证删除每一份副本。如需帮助确认存储了哪些 Routine 数据，请联系支持。

本网站

本网站使用 Cloudflare Web Analytics 来衡量访问量和性能，不使用分析 Cookie。网站由 GitHub Pages 托管；为提供网站服务并保障安全，GitHub Pages 可能会处理请求信息，包括你的 IP 地址。请参阅 GitHub 隐私声明. Cloudflare Web Analytics 隐私说明.
