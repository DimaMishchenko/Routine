Privasi

Routine 1.1.0 · Diperbarui 3 November 2026

Rutinitas Anda dan iCloud

Rutinitas, progres, riwayat, dan pengaturan pengingat Anda disimpan di perangkat Anda. Saat iCloud tersedia, Routine dapat menyinkronkannya melalui CloudKit milik Apple menggunakan akun Apple Anda. Layanan tersebut mengikuti pengaturan iCloud dan pencadangan Apple. Routine tidak memiliki akun atau server sinkronisasi tersendiri.

Pengingat dan kunci aplikasi

Pengingat menggunakan notifikasi lokal dengan izin Anda. Autentikasi melalui Face ID, Touch ID, dan kode sandi perangkat ditangani oleh sistem operasi. Routine tidak menerima templat biometrik. Anda dapat mengelola izin di pengaturan sistem.

Analitik dan dukungan

Routine tidak menyertakan analitik pengembang, pelacak iklan, atau pelaporan kerusakan pihak ketiga. Aplikasi dan sistem operasi dapat menghasilkan log diagnostik lokal.

Jika Anda memilih untuk mengirim email ke dukungan, draf dari aplikasi menyertakan tanggal, model perangkat, versi sistem operasi, dan versi aplikasi. Periksa atau hapus detail tersebut sebelum mengirim. Dukungan hanya menerima apa yang Anda pilih untuk dikirim; hindari informasi rutinitas pribadi. Email dan GitHub memiliki kebijakan privasi masing-masing, dan issue GitHub bersifat publik.

Menghapus data

Di iPhone dan iPad, menghapus aplikasi biasanya menghapus data lokal aplikasi. Di Mac, menghapus aplikasi dapat menyisakan data di kontainer lokal aplikasi dan App Group bersama. Data CloudKit dan cadangan iCloud mungkin tetap tersimpan di akun Apple Anda dan perlu dikelola secara terpisah melalui pengaturan penyimpanan iCloud Apple. Menghapus aplikasi tidak menjamin semua salinan ikut terhapus. Hubungi dukungan untuk bantuan mengidentifikasi data Routine yang tersimpan.

Situs web ini

Situs web ini menggunakan Cloudflare Web Analytics untuk mengukur kunjungan dan performa tanpa kuki analitik. Situs ini dihosting oleh GitHub Pages, yang dapat memproses informasi permintaan, termasuk alamat IP Anda, untuk menyajikan dan mengamankan situs. Lihat Pernyataan privasi GitHub.
